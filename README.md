# ETF Starter · KOSPI200 ETF LAB

ETF 입문자를 위한 **탐색 → 비교 → 이해 → 시뮬레이션** 서비스입니다. 기존 KOSPI200 ETF Lab은 첫 번째 분석 콘텐츠로 보존합니다.

## 새 입문 서비스

- `#/` 카테고리 중심 홈
- `#/explore` 실제 스냅샷의 9개 ETF 종류별 탐색·검색
- `#/compare` 최대 3개 선택, 1·3개월/1년 가격 수익률과 기간별 차트
- `#/etf/069500` 상세 정보·기간별 차트·데이터 확보 상태
- `#/simulator` 월 적립식·같은 총액 일시 투자 시나리오
- `#/learn` ETF·NAV·보수·분배금 등 15개 설명과 가상 예시
- `#/kospi200` → `kospi200.html`: 기존 연도별 성과·위험·차이 확대 분석

GitHub Pages 서브경로와 로컬 파일을 지원하는 해시 라우팅입니다. 별도 서버·DB·프레임워크는 추가하지 않았습니다.
순자산·총보수·상장일은 항목별 기준일을 가진 공식 자료를 연결했습니다. 분배금·NAV·구성종목은 아직 미확보이며 mock 데이터를 넣지 않습니다.
거래량은 가격과 같은 날짜의 `volumes`에서 읽습니다. 필드가 없는 과거 스냅샷은 미확보로 표시합니다.
주식·채권·금/원자재·테마/산업의 네 종류와 지역·배당 전략 필터를 제공합니다. 등록 상품 범위는 아래 표를 확인하세요.

### 적립식 계산 기준

선택 구간의 첫 관측 거래일과 이후 매월 첫 관측 거래일 종가에 정수 좌수를 매수합니다.
잔여 현금은 다음 납입일까지 이자 없이 보유합니다. 평가금액 = 좌수 × 종가 + 현금입니다.
분배금·세금·거래비용을 제외하며, 공급자 가격의 조정 이력은 미검증이므로 실제 거래·보유좌수 재현 결과로 해석하지 않습니다.
납입금 대비 수익률은 IRR이나 연환산 수익률이 아닙니다. MDD는 입금 전 평가액 / 전일 입금 후 평가액을 일별 연결한 지수의 고점 대비 낙폭입니다.
일시 투자는 적립식 총 납입금을 시작일부터 보유했다고 가정하므로 자금 투입 시점이 다릅니다.
데이터 범위를 벗어난 날짜, 두 관측일 미만, 0 이하·비유한 금액은 거부합니다.

실제 분배금 재투자는 제공하지 않습니다. 지급 이력·분배락·기업행동·가격 조정 기준을 검증한 후 활성화해야 이중 계산을 피할 수 있습니다.

## 화면에서 확인할 수 있는 것

- 전체 기간 및 연도별 가격 수익률, CAGR, 연환산 변동성, Sharpe, 최대 낙폭
- 누적수익률·종가·낙폭 차트
- **차이 확대:** KODEX 200을 0% 기준으로 놓고 상대 성과를 표시하는 차트와 표
- 마지막 공통 거래일과 수집 시각

상대 성과는 `(1 + ETF 누적수익률) / (1 + KODEX 200 누적수익률) - 1`입니다.
단순 수익률 차이(%p)와 다릅니다. 차이 확대 차트는 세로축을 자동 조절하므로 전체 수익률 차트와 함께 해석합니다.

**CAGR이 —인 이유:** 화면에서는 경과일수 / 365.25가 1 미만이면 CAGR을 숨깁니다.
2026 YTD처럼 짧은 기간을 연환산해 오해하는 것을 줄이기 위한 표시 규칙입니다.
선택한 연도에 따라 연말 거래일 사이가 365.25일 미만이면 과거 연도에서도 —가 표시될 수 있습니다.
전체 기간을 선택하면 장기 CAGR을 확인할 수 있습니다.

## 실행하기

Python 3.11을 기준으로 구성했습니다.

```bash

cd KOSPI200-ETF-LAB
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

네 ETF의 데이터를 수집하고 웹페이지 스냅샷을 갱신합니다. 인터넷 연결이 필요합니다.

```bash

python -m http.server 8000 --directory docs
```

브라우저에서 [로컬 미리보기](http://localhost:8000)를 엽니다.
저장된 `docs/data.js`가 있으면 `docs/index.html`을 직접 열어 오프라인으로도 볼 수 있습니다.
로컬 파일은 공개 사이트의 갱신 결과를 자동으로 받지 않으므로, 최신 저장소를 받거나 수집 명령을 다시 실행해야 합니다.

단일 ETF 분석도 실행할 수 있습니다.

```bash
python -m src.data_loader --symbol 069500 --start 2023-01-01 --end 2025-12-31
python -m src.backtest --input data/raw/069500_naver_2023-01-01_2025-12-31.csv
```

분석 결과는 `data/processed/`와 `results/`에 저장됩니다.
단일 ETF 수집은 FinanceDataReader의 NAVER 소스를 사용하며, `--provider yahoo`로 Yahoo 어댑터를 선택할 수 있습니다.
자동 비교 수집은 NAVER 차트 endpoint를 직접 사용합니다. 공급자가 실패해도 다른 공급자의 데이터를 자동 혼합하지 않습니다.

## 계산과 검증

| 지표 | 정의 |
|---|---|
| 일별수익률 | P[t] / P[t-1] − 1 |
| 누적수익률 | P[t] / P[0] − 1 |
| CAGR | (P끝 / P시작)^(365.25 / 경과일수) − 1 |
| 연환산 변동성 | 일별수익률 표본 표준편차 × √252 |
| Sharpe | (일별수익률 평균 − 일별 무위험수익률) / 표본 표준편차 × √252 |
| 최대 낙폭 | min(P[t] / 해당 기간 누적 최고가격 − 1) |

웹사이트의 무위험수익률은 연 0%입니다. 변동성이 0이면 Sharpe는 정의하지 않습니다.
연도별 수익률은 전년도 마지막 공통 거래일 종가를 기준으로 첫 거래일 수익까지 포함합니다.

양수·유한 가격, 중복 날짜, 거래일 일치 여부와 최신 기준일을 검증합니다.
결측 가격을 임의로 채우지 않으며, 일부 ETF 수집 실패나 과거 데이터 범위 축소가 발생하면 새 데이터 게시를 중단합니다.
원본 스냅샷과 메타데이터의 SHA-256 체크섬으로 저장 데이터의 무결성을 확인합니다.

## 해석의 한계와 다음 연구

현재 결과는 **공급자 종가 기반 가격 성과**입니다.
분배금 재투자와 공급자의 과거 가격 조정 정책을 독립적으로 검증하지 않았으므로 총수익률이나 운용 능력 순위로 해석하지 않습니다.
거래비용·세금은 제외하고, 보수는 가격에 반영된 범위 외에 별도 차감하지 않습니다.
공통 날짜 검증은 거래소 공식 캘린더와의 완전성 대조를 대신하지 않습니다.
KODEX 대비 상대 성과는 지수 대비 추적오차가 아닙니다.

후속 연구는 분배금 포함 총수익률, NAV·지수 기준 추적차이와 추적오차, 거래대금·호가 스프레드 비교입니다.
Momentum·Value·Quality 전략은 향후 확장 과제로, 현재 매매 신호·체결 엔진은 구현하지 않았습니다.

## ETF 종류별 탐색

홈은 네 종류로 묶고, 지역·배당은 탐색 필터로 구분합니다. 모든 국내 ETF를 망라하는 서비스는 아닙니다.

| 종류 | 등록 ETF |
|---|---|
| 주식 | KODEX/TIGER/RISE/PLUS 200, TIGER 미국S&P500, PLUS 고배당주 |
| 채권 | KODEX 국고채3년 |
| 금·원자재 | KODEX 골드선물(H) |
| 테마·산업 | KODEX 반도체 |

`config/explore-etfs.json`에 상품별 종류·지역·전략·기초지수·유형·설명·공식 출처를 관리합니다.
`docs/explore-data.js`는 탐색용 9개 ETF, 기존 `docs/data.js`는 KOSPI200 Lab 4개 ETF용입니다.
모두 국내 상장·원화 거래 ETF이며, 미국 주식 ETF의 원화 성과는 환율 영향을 포함합니다.
다른 자산·지수끼리의 성과 차이를 운용 능력 순위로 해석하지 않습니다. 금 선물은 금 현물과 다릅니다.

```bash
python -m src.update_data --universe config/explore-etfs.json --output docs/explore-data.js
node tests/test_categories.cjs
```

자동 갱신 작업은 두 데이터 파일을 수집하고 둘 다 성공한 경우 함께 커밋합니다.
추가 상품의 기본 정보 중 확인되지 않은 보수·순자산·상장일과 분배금은 미확보로 표시합니다.
전체 범위의 상품과 같은 거래일을 요구하므로 추후 신규 상장 상품을 더할 때 장기 이력이 잘리지 않도록 상품별 데이터 구조 전환이 필요합니다.
원유·은·다른 산업 등의 미등록 상품, 실제 분배금 재투자와 구성종목 기여도는 이번 확장에 포함하지 않습니다.
