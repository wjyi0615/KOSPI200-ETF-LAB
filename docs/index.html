01

데이터 확보

네이버 731개, Yahoo 712개 관측치를 같은 요청 기간에 확인했습니다. 더 많은 관측치를 반환한 네이버를 사용하며, 두 공급자의 가격은 혼합하지 않습니다.

02

수익과 위험 측정

일별수익률에서 연환산 변동성과 Sharpe를 계산합니다. CAGR은 실제 경과일수, 변동성은 연 252거래일과 표본 표준편차를 사용합니다.

03

재현성과 검증

원본 파일의 출처·조회 시각·SHA-256을 기록합니다. 공식, 비정상 입력, 데이터 무결성과 수집 경계를 확인하는 Python 테스트 6개를 통과했습니다.

계산식 확인하기

일별수익률 = Pₜ / Pₜ₋₁ − 1

누적수익률 = Pₜ / P₀ − 1

CAGR = (P끝 / P시작)^(365.25 / 경과일수) − 1

연환산 변동성 = 일별수익률 표본 표준편차 × √252

Sharpe = 일별수익률 평균 / 표본 표준편차 × √252 (무위험수익률 0%)

MDD = min(Pₜ / 해당 시점까지의 최고가격 − 1)

첫 관측일은 수익률 표본에서 제외합니다. 변동성이 0이면 Sharpe는 정의하지 않습니다.
